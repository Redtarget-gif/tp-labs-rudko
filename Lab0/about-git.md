1. Чем ветка отличается от копии папки с проектом?
Ветка в Git — это не копия всех файлов, а просто ссылка на конкретный коммит. Когда создаётся копия папки, дублируются все файлы, что занимает много места и усложняет синхронизацию. Ветка же работает как указатель, который двигается по истории коммитов, а сами файлы хранятся в репозитории в единственном экземпляре.

2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?
История останется полностью сохраненной. Папка .git содержит всю базу данных проекта со всеми коммитами, ветками и версиями файлов. Если я удалю только рабочие файлы, но оставлю .git, я всегда смогу восстановить любой файл из любого коммита с помощью команд git checkout или git restore.

3. Зачем нужен Pull Request, если можно коммитить сразу в main?
Pull Request нужен для контроля качества и совместной работы. Если коммитить напрямую в main, то ошибки сразу попадают в основную ветку, которую используют другие разработчики. PR позволяет показать изменения другим, получить обратную связь, обсудить код и только после одобрения влить его в main. В нашем курсе это способ сдачи работы — преподаватель проверяет код в PR и либо одобряет, либо просит исправить.
